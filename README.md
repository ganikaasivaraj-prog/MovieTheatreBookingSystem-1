\# Movie Theatre Ticket Booking and Box Office Analysis System



\## Project Overview

The Movie Theatre Ticket Booking and Box Office Analysis System is a database-driven application developed using Java, MySQL, JDBC and Python.



It helps manage movie shows, customer details, ticket bookings, payments, cancellations and box office reports.



\## Technologies Used

\- Java

\- JDBC

\- MySQL

\- Python

\- Pandas

\- Matplotlib

\- MySQL Connector



\## Main Modules

1\. Movie Management

2\. Show Management

3\. Customer Management

4\. Ticket Booking

5\. Payment Management

6\. Booking Cancellation

7\. Box Office Reports

8\. Python-Based Data Analysis



\## Key Features

\- Display movies and available shows.

\- Register and search customers.

\- Book movie tickets.

\- Calculate ticket payment amounts.

\- Cancel eligible bookings.

\- Generate revenue and booking reports.

\- Analyse movie-wise revenue using Python.

\- Generate a box office revenue chart.



\## Database

Database name: `movie\_theatre\_db`



The project uses MySQL tables to manage movies, screens, shows, customers, bookings, payments and cancellations.



\## Python Analysis

Python connects to the MySQL database and uses Pandas to retrieve box office information. Matplotlib generates a movie-wise revenue chart.



\## How to Run

1\. Install JDK and MySQL.

2\. Create and configure the `movie\_theatre\_db` database.

3\. Add the MySQL Connector JAR to the Java project.

4\. Configure your database connection credentials locally.

5\. Compile and run the Java application.

6\. Install the required Python packages:

&#x20;  `pip install pandas matplotlib mysql-connector-python`

7\. Run `PythonAnalysis/box\_office\_analysis.py`.
